TGF / Click & Create and Multimedia Fusion 2.0
Multimedia Fusion 1.5 Extensions folder (optional)
MMF 1.0 and 1.5 games carry their extension objects (.cox files), but often not the names the editor displays for them. If Multimedia Fusion 1.5 is installed, point KlikBack at its Extensions folder and the missing names are recovered from your installed copies - you are also warned if an installed extension is older than the one the game was built with. KlikBack only scans this folder: nothing in it is copied or changed. Leave it blank to skip the scan; games still decompile either way. (MMF 2.0 games use their own folder, below.)
Multimedia Fusion 2.0 Extensions folder (optional)
A different install for a different job. Point KlikBack at your Multimedia Fusion 2 Extensions folder (the folder itself, holding the .mfx files) and two things happen: an extension object in the recovered project gets its module’s own icon, exactly as the editor would draw it, and the card above says which of a game’s modules your editor has, by name and version. A module the folder lacks falls back to a stand-in icon and is named in the report. KlikBack only reads this folder - nothing in it is copied or changed - and it never goes looking for one: the folder you give is the only one it opens.
